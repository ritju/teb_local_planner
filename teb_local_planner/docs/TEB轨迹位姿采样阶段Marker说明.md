# TEB 轨迹位姿采样阶段 Marker

在 RViz 添加 `MarkerArray`，选择 `teb_sampling_debug` 话题（例如 `/teb_sampling_debug`；实际名称以节点命名空间及重映射为准，可用 `ros2 topic list` 确认）。`controller_server.debug_mode=true` 时发布。Marker 使用 `map_frame`，每次发布先清空该话题的上一组标记，寿命为 2 秒。

| 命名空间 | 颜色 | 含义 |
| --- | --- | --- |
| `teb_sampling_initial` | 蓝色 | 本轮 `optimizeTEB()` 开始时的位姿；可能是新路径种子，也可能是复用并裁剪后的旧轨迹。 |
| `teb_sampling_after_autosize` | 橙色 | 最后一轮外层优化中，`autoResize()` 执行后、该轮图优化前的位姿。标签中的 `outer` 是外层轮次；`autoResize off` 表示当前未启用自动增删点。前几轮图优化也可能已移动这些位姿，因此初始与该阶段的差异不全由增删点产生。 |
| `teb_sampling_optimized` | 绿色 | 最后一轮优化后的原始位姿，尚未加入碰撞可行性检查的插值点。标签包含检查结果和候选对象地址，可与 `[TEB 可行性事件]` 日志对照。 |

每个阶段的细线连接位姿顺序，圆点表示位姿采样点，短线表示朝向；加粗的线段及 `max turn i->i+1` 文本标出**相邻转角最大的段**。阶段标签显示采样点数 `n` 与最大相邻转角 `max_dyaw`。这些标记展示的是位姿序列，不代表车辆轮廓或连续扫掠区域。

Marker 在候选轨迹的可行性检查结果产生时发布；即使候选被拒绝，也会显示。多拓扑规划依次检查多个候选时，话题最终显示**最后一个被检查的候选**；若找到可行候选，则显示该可行候选。优化本身失败时也会发布已捕获的阶段，结果写为建图失败、优化失败或数值断言失败。
