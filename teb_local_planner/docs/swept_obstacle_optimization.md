# TEB 矩形轮廓段内扫掠约束

## 实现范围

- 保留 autoResize 的位姿顶点数。静态障碍段内边连接相邻两个原有位姿，在固定比例 s 处约束优化轮廓的带符号距离。
- 对机器人中心线段的包围盒外扩轮廓最大顶点半径、障碍关联距离和裕度；障碍包围盒相交后才计算 0.25、0.5、0.75 三个试探位置，选择距离最小的候选建边。已有穿透的候选全部保留，接近但未穿透的候选受每段边数预算限制；截断数量写入中文日志。
- 轮廓复查利用中点距离与平移、旋转运动上界证明子段安全；不能证明则继续二分，达到检查预算仍不确定时拒绝轨迹。
- 栅格或轮廓检查失败时记录段号、比例和失败位姿。每控制周期最多修复一次：固定顶点数量，在失败的精确插值比例建边；栅格失败时至少保留一个附近代价图单元形成的障碍边，再建图并短迭代。修复后必须重新通过检查。
- 同伦规划在移除失败候选之前调用该候选自己的修复和复查。

## 参数

| 参数 | 当前 teb_params.yaml 值 | 含义 |
| --- | ---: | --- |
| swept_obstacle_enable | true | 启用静态障碍段内建边、复查与修复 |
| swept_obstacle_margin | 0.05 m | 候选包围盒裕度；也是轮廓一致性容差下限 |
| swept_obstacle_trigger_dist | 0.35 m | 低于此轮廓距离才建边 |
| swept_obstacle_max_edges_per_segment | 3 | 每段接近障碍的边数预算；穿透项不受此预算截断 |
| swept_check_max_evals | 128 | 每段每障碍的连续包络验证上限；不能证明安全则拒绝 |
| swept_repair_max_attempts | 1 | 0 关闭修复；正值目前均限为一次 |
| swept_repair_inner_iterations | 3 | 修复时的 g2o 迭代次数 |
| swept_repair_budget_ms | 20 ms | 修复后的耗时门限，超出则拒绝 |

通用默认配置未启用此功能，teb_params.yaml 显式启用。启用时优化轮廓须与 costmap 轮廓在容差内一致，否则拒绝候选。
outdoor_cleaner_2.yaml 也已显式启用，并将优化轮廓设为与其局部代价图相同的矩形。

## 可视化 Marker

调试时设置 debug_mode 为 true，订阅 teb_swept_debug。

| 命名空间 | 颜色与形状 | 含义 |
| --- | --- | --- |
| swept_danger_segments | 橙色线段 | 建边时靠近静态障碍的相邻位姿段 |
| swept_edge_build_samples | 青色圆点 | 建边时固定的段内采样位置，用于与优化结果对照 |
| swept_candidate_obstacles | 黄色圆点 | 已建立段内边的障碍物质心；一个障碍可能对应多个点 |
| swept_failure_footprint | 红色轮廓 | 复查失败时的机器人轮廓 |
| swept_failure_label | 红色文字 | 失败段索引、比例和原因 |

每次发布清除本话题旧 Marker。多同伦候选时显示最近检查的候选。

## 安全边界与性能

障碍边是软约束，不能替代最后的栅格和轮廓可行性检查。连续包络认证针对障碍容器中的静态几何；代价图独有障碍仍由栅格检查发现，在失败附近补点后修复。动态障碍继续由现有动态预测与硬检查处理。没有可用障碍几何时不作无依据的重优化。

修复预算是完成后的结果门限，不能抢占已运行的 g2o 迭代。需要记录建图、优化、段内检查和修复耗时及控制周期 P95。预算耗尽或边数截断时仍须执行最后的检查。
