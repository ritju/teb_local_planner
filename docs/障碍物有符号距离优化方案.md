# TEB 障碍物有符号距离优化：两阶段方案

## 问题与目标

现有多边形距离计算是轮廓边界的无符号距离：点进入车体内部后距离可能增大，两个多边形相交时距离恒为零。前者可能使侵入后的代价下降，后者使数值梯度消失。优化成功因此不等于避开障碍。

目标是先修正离散自由位姿的障碍代价和推出梯度，再补充相邻位姿之间的连续运动约束。提高权重不能代替正确距离语义。最终硬碰撞检查仍然需要保留。

## 第一阶段：距离、代价和障碍关联（本次实现）

### 接口与算法

- 新增 `BaseRobotFootprintModel::optimizationDistance()`，返回 `OptimizationDistance`：`signed_distance`（分离正、接触零、侵入负）及平移方向的 `escape_normal`。保留 `calculateDistance()` 和公共无符号几何函数，避免改变其他调用方含义。
- `PolygonRobotFootprint` 实现新距离，支持点、圆、线段、胶囊和多边形障碍。其他 footprint 模型保留原距离语义和数值梯度；本次不宣称修复它们原有的所有包含问题。
- 对车体 A 与障碍 B 构造差集点的凸包 A-B（配置空间碰撞区域）。原点在外时为真实最短分离距离；在内时，原点到边界距离的负值即最小平移穿透深度。这与凸几何的 SAT/GJK-EPA 穿透目标一致，能正确处理完全包含。圆/胶囊在点/线段距离基础上扣除半径。
- 非凸输入使用凸包保守包络，不将凸算法直接套在原始凹轮廓上。可能丢失凹槽可通行空间；若需保留凹槽，后续应增加凸分解及组合碰撞处理。非有限、空或不支持的几何明确报错，不作为自由空间。
- 接触及最近边等距时选确定的单侧平移次梯度，避免中心数值差分返回零。平移采用该次梯度，yaw 使用有符号距离的中心差分；最近特征切换处函数不光滑，不能承诺全局收敛。

### 优化图接入

- `EdgeObstacle`、`EdgeInflatedObstacle` 使用新距离，保留原残差 `max(0, min_obstacle_dist + penalty_epsilon - d)` 和平方信息矩阵权重。
- 两种边同步更新雅可比；障碍指数的链式导数及膨胀距离残差均保留。
- 默认非 legacy 障碍关联使用同一有符号距离，`d <= 0` 的障碍强制纳入关联，不受远距离筛选门槛影响；外层迭代仍重建关联。legacy 关联策略不在本次重写范围，但建立的静态障碍边会使用新距离。
- 不改首尾固定顶点策略，不给固定顶点制造无法下降的优化目标。起点/终点碰撞不能依靠自由位姿优化自动解决，需要由目标可用性、已有终点占用处理和最终可行性检查共同处理；本次不承诺固定端点或整段轨迹安全。
- 本次修复静态/当前时刻的上述障碍边；动态障碍未来位置的距离边、控制器/碰撞监控器、普通硬碰撞检查策略保持原实现。

### 参数

不新增开关，不调整现有 YAML 参数。当前导航配置示例：`min_obstacle_dist=0.15`、`penalty_epsilon=0.05`、`weight_obstacle=1000`、`inflation_dist=0.4`、`weight_inflation=1`、`obstacle_cost_exponent=1`。

零障碍残差门槛约为 0.20m。负距离会持续增加残差，越深侵入代价越大。非零权重仍是软约束，局部极值、其他目标、迭代次数和固定端点可能使最终间距不足，必须检查最终结果，不能只看求解器返回值。

`obstacle_association_force_inclusion_factor`、`obstacle_association_cutoff_factor` 继续用于正距离筛选；相交障碍直接纳入。`weight_adapt_factor` 仍按原外层循环增强权重。本次不通过更改这些参数掩盖几何问题。

### 验证要求

覆盖点的内/外/接触、完全包含、相交、旋转、反序顶点、重复和退化几何、圆/胶囊、无效输入；检查有符号距离及沿推出方向代价下降。对称穿透初值必须能通过实际 g2o 障碍边优化离开碰撞，另用真实 TEB 优化轨迹检查自由位姿最小有符号间距。

## 第二阶段：连续段约束（本次不实现）

- 对相邻自由位姿之间增加采样障碍边，同时连接前后两个顶点，不能只做优化结束后的采样检查。
- 采样依据平移距离及旋转轮廓运动量，使用 `平移距离 + 外接半径 × 转角绝对值` 控制间隔；特别验证长矩形车体转弯扫掠。
- 采样位姿使用同一套有符号距离与一致梯度；研究固定/自适应采样对求解稳定性和控制周期的影响。
- 验证两端安全、中段穿障，长车体角点扫掠，窄障碍、窄通道及障碍变化。同时评估运行耗时与发布控制频率。
- 完善固定端点不可用的准入和恢复策略；继续保留完整 footprint、未知/出图处理及轨迹最终安全检查。

## 部署与边界

新增虚接口改变 footprint 模型类的 ABI。需要重编 TEB 库及相关测试/外部自定义 footprint 插件，重启导航加载新库。不会自动重启正在运行的导航或发送运动任务。

第一阶段不构成连续运动无碰撞证明，不解决传感器漏检、轮廓小于实车、延迟或实际跟踪偏差。运行耗时和场景效果需在重启后的仿真/实车中验证。

## 相交位姿诊断日志

诊断沿用 `controller_server.ros__parameters.debug_mode`，不调整节点日志等级。启动后可执行：

```bash
ros2 param set /controller_server debug_mode true
```

### `[TEB Clearance]`

在既有轨迹可行性检查结束或拒绝候选时输出。每次分为“轨迹检查”“全轨迹轮廓诊断”“最危险几何”三行，三行共用候选地址；原因以中文显示，并保留括号内英文原因代码供搜索。开启 debug_mode 后，每次检查都会额外扫描实际 `obstacles_` 与所有离散轨迹位姿，以便识别短暂相交；相同状态每 1 秒最多打印一次，拒绝/通过/通过但侵入/通过但距离无效的状态切换立即打印。额外扫描有计算开销，问题定位完毕可关闭 debug_mode。

- `candidate`：本次 TEB 实例地址，区分不同候选；`time_ns` 为 ROS 检查时间，`frame` 为优化坐标系。
- `feasible`、`reason`：既有检查结果，原因包括 `checks_passed`、`costmap_pose_rejected`、`costmap_interpolation_rejected`、`contour_rejected`。
- `min_signed`：全部位姿到实际优化障碍的最小当前时刻有符号距离；`min_free_signed`：仅自由位姿的最小值。负数表示侵入，不代表原始代价图或连续运动扫掠结果。
- `penetrating_pairs`、`below_min_pairs`、`invalid_pairs`：侵入、低于 min_obstacle_dist、无法计算或非有限距离的位姿/障碍对数量。无有效对时最小值为 inf。
- `worst_pose`、`pose=(x,y,yaw)`、`fixed`、`in_checked_range`：最坏位姿、是否固定及是否在本次原有检查范围内；`checked_until` 为该范围末端或失败时的位姿下标。插值检查失败的日志指向所属离散段下标，并不表示该离散点自身必然碰撞。
- `worst_obstacle`、`type`、`dynamic`、`centroid`、`geometry`：对应障碍的当前容器下标、类型、动态标记、质心及前 16 个几何点；`obstacle_vertices` 给出总点数。下标不跨周期保持，不是传感器原始 ID。
- `static_associated`、`static_associated_pairs`：原有静态关联缓存中是否包含该障碍及关联对总数，仅用于分析默认非 legacy 策略，不是实际 g2o 所有边/动态边的计数；结合 `legacy_assoc` 解读。
- `wall_guides_excluded`：不参加普通障碍距离扫描的墙线引导对象数量。它们采用专用墙边距离代价，不能当作普通实体障碍距离解释。
- `min_dist`、`epsilon`、`weight`、`iterations`、`contour_check`：当前实际配置；`opt_inscribed`、`model`、`costmap_footprint` 辅助对照优化模型和硬检查轮廓。

原有检查返回可行但最小有符号距离为负时，以 WARN 输出“检查虽通过，但全轨迹诊断发现轮廓侵入”；检查返回可行但存在无效距离时输出对应中文告警。这些是诊断告警，不会改变原有返回值、触发停车或增加新的安全准入条件。“最危险几何”若标记“全轨迹诊断点，非本次拒绝位置”，应先按第一行的拒绝原因与检查段定位当前拒绝。

`weight` 是配置基础权重，实际边的信息矩阵还会乘外层 `weight_adapt_factor`；加权代价同时参考已有 `[TEB cost dbg]`。判读时可按以下顺序定位：

| 日志现象 | 排查方向 |
|---|---|
| min_free_signed < 0，最坏位姿 fixed=0，且静态非 legacy 障碍 static_associated=1 | 已关联障碍仍残留侵入，检查代价竞争、迭代及初始化 |
| 同上但 static_associated=0 | 检查外层建图关联及最后一次内层优化后进入新障碍的情况；缓存不是动态边统计 |
| min_signed < 0，最坏位姿 fixed=1，而 min_free_signed >= 0 | 优先检查实际起点或固定终点是否已碰撞，不能据此认定自由位姿优化失败 |
| 全部离散距离非负，但画面仍相交 | 对照优化/硬检查 footprint、输入坐标系、消息时序、墙线裁剪和两离散点之间的运动 |
| reason=costmap_interpolation_rejected，但离散最小距离非负 | 检查段内碰撞，而非仅检查两端位姿 |

### `[TEB ObstacleInput]`

每秒汇总 converter 输入数量、`points_r0`（单点且半径不为正）、圆、线、多边形数量，以及实际新增、跳过和墙线裁剪数量。记录贴边/墙线过滤状态、输入/有效/目标坐标系、消息头时间有效性和 age。`stamp_valid=0, age=-1` 表示无法用消息头判断新鲜度，不能据此断定过期；当前 BaseCostmapToPolygons::getObstacles() 的头可能为空。空时间戳的诊断不改变原有使用方式。

出现 `DROPPED_ZERO_RADIUS_POINTS` 表示现有 converter 接入缺少零半径点分支；记录第一个被跳过点的坐标。`FRAME_MISMATCH` 表示 converter 输入与目标坐标系不同，而当前接入直接使用坐标。这里仅增加观测，不在本次日志修改中修复这两类接入行为。

### `[TEB GridCheck]`

记录原有格网检查抛出的异常及位姿。`rejected=1` 表示原逻辑拒绝；`rejected=0` 或 `preserved_as_valid=1` 表示该异常仍按原实现放行。对照 `[TEB Clearance]` 可以识别距离侵入却通过格网检查的情况。

建议保留发生相交前后数秒的以上三组日志及 `[TEB cost dbg]`，同时记录 local_plan、teb_costmap_obstacles、局部代价图和 footprint。各数据需对照时间和坐标系；转换器输出、墙线裁剪后的优化障碍与原始代价图不应混为同一几何。
